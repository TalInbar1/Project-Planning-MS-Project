# Project Planning with MS Project

### Project Overview
A complete project plan built in **MS Project**, covering the full project life cycle from defining the budget framework and time window to the final financial closing.

### What We Did
* **Budget framework:** The first activity sets the budget and the time window, which every later decision depends on. A cost reserve was defined for price increases.
* **Schedule:** Activities, durations, dependencies, resources and a Gantt chart, with critical path analysis.
* **Milestones and summary activities:** A zero-duration milestone marks the end of the planning and procurement phase, and a hammock (summary) activity groups the administrative tasks for one view of their progress.
* **Stakeholder mapping:** Each stakeholder, including suppliers and regulators, and how the project connects with them.
* **Risk management:** Negative risks and positive opportunities, each with a planned response.
* **Performance metrics:** CPI and SPI for budget and schedule performance, plus a subjective satisfaction measure.
